- 每个业务页面采用 index.vue + index.scss + index.d.ts 三件套同目录组织，类型定义与样式内聚于页面目录。
- API 按领域拆分为 `src/api/<domain>/index.ts`，每个文件只导出该域的请求函数，统一通过 `@/utils/request` 的 get/post/put/del 泛型方法访问。
- HTTP 拦截器在请求阶段注入 Authorization 与 SM2 签名头（x-sign/x-timestamp/x-nonce），响应阶段集中处理 401 自动续签与全局错误提示。
- Pinia store 使用 Composition API 风格 defineStore，token/refreshToken 读写时同步持久化到 localStorage 的 admin_token/admin_refresh_token。
- 路由通过 meta.title/meta.icon/noAuth 描述页面标题、图标与鉴权策略，由 router guard 统一消费。
