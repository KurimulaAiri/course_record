模块为独立的前端工程（package.json 中 name 为 admin-frontend），采用 Vite 8 (Rolldown) + Vue 3.5 + TypeScript 6 构建。

- 入口与框架装配：`src/main.ts` 依次挂载 Pinia、Router、ElementPlus（含 dark css-vars），并在挂载前初始化 `useThemeStore` 以设置 data-theme。
- 路由与权限：`src/router/index.ts` 使用 `createWebHistory` 静态声明所有页面路由，通过 `meta.noAuth` 标记免认证页面；全局 `beforeEach` 守卫基于 `localStorage.admin_token` 做登录态校验并驱动 NProgress 进度条。
- 状态管理：`src/stores/` 下按领域划分 Pinia store（user、theme、counter），其中 user store 同时持有 token/refreshToken/userInfo/roles/menus 并与 localStorage 双向同步，还提供 `fetchMenus` 调用后端菜单树接口。
- HTTP 层：`src/utils/request.ts` 封装 Axios 实例，统一处理 Bearer Token、SM2 签名头（x-sign/x-timestamp/x-nonce）、401 自动续签（带并发排队重试）以及全局 ElMessage 错误提示；对外暴露 get/post/put/del 泛型方法返回 `ApiResponse<T>`。
- API 分层：`src/api/<domain>/index.ts` 按业务域拆分（auth/class/course-record/system/* 等），每个文件仅导出对应后端的函数，依赖 `@/utils/request` 的 http 方法。
- 视图组织：`src/views/` 按功能域分目录（dashboard/login/profile/system/* /business/*），每个页面采用 index.vue + index.scss + index.d.ts 三件套，配合 `src/components/page-help` 通用组件与 `src/config/help-content.ts` 帮助文案。
- 构建与分包：`vite.config.ts` 配置 `manualChunks` 将 element-plus、@element-plus/icons-vue、vue 生态、axios/sm-crypto/nprogress 拆为独立 chunk，生产关闭 sourcemap，assetsInlineLimit=4KB。
- 测试与 E2E：`src/__tests__/App.spec.ts` 使用 Vitest + @vue/test-utils；`e2e/vue.spec.ts` 使用 Playwright；`pipeline/Jenkinsfile` 定义 CI 流水线。
