Maven 多模块聚合工程（根 pom.xml 声明 modules: common/gateway/auth-service/business-service/admin-service），以 Spring Boot 4.0.4 + Spring Cloud 2025.1 + Spring Cloud Alibaba 2025.1 为骨架，Nacos 同时承担注册中心与配置中心。
- 分层：每个业务 service 均遵循 controller → service/impl → mapper → resources/*Mapper.xml 的 MyBatis-Plus 分层；common 模块集中存放 entity/dto/vo/converter/annotation/interceptor/filter/config/util 等跨服务复用代码，被其余四个模块依赖。
- 网关层 gateway 通过自定义 JwtAuthFilter 做统一鉴权转发，并排除 DataSource 自动装配以最小化启动开销。
- 认证域 auth-service 负责登录/注册/菜单权限/平台绑定，使用 Redis 缓存 Token 黑名单与 BindTokenCache；admin-service 暴露管理员端 CRUD 接口并通过 Feign 调用 auth-service 获取用户上下文。
- 业务域 business-service 承载课程、班级、排课、上课记录、学生/教师/机构等核心领域逻辑，配合 DeductNotifyAspect / StudentCountAspect 等 AOP 切面处理扣课与人数统计等横切关注点。
- 数据访问：所有实体继承 BaseEntity/RoleBaseEntity，MyBatis-Plus 在 common 中统一开启分页与乐观锁插件；mapper XML 按包路径 classpath*:com/shiroko/mapper/*.xml 扫描。
- 部署：各服务独立 Dockerfile，顶层 docker-compose.yml 一键编排，Jenkinsfile 提供 CI 流水线入口。
