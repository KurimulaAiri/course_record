- 每个 MCP Tool 通过 `server.registerTool(name, { description, inputSchema }, handler)` 三件套声明，handler 始终返回 `{ content: [{ type: 'text', text }] }` 结构。
- 输入参数一律使用 zod schema 描述类型与默认值，并在 handler 中通过解构获取，未提供的字段回落到 `default()` 值。
- 对外部系统的 HTTP 请求统一经 `httpFetch` 封装，设置 `AbortSignal.timeout(15000)` 超时，并以 `{ status, data, text, headers }` 标准化响应。
- 需要认证的子系统采用「登录缓存 token/cookie + 401 时刷新并重试一次」的模式（见 `ensureNacosToken`、`sentinelApi`）。
- 写操作类 Tool 内置白名单/黑名单安全校验（如 `execute_db_update` 禁止 DROP/TRUNCATE/GRANT/REVOKE，DDL 需显式 `allow_ddl=true`），错误以文本形式返回而非抛异常。
- 环境变量集中定义于文件顶部，带空字符串或合理默认值，敏感项（token/password）允许为空并在运行时检查提示。
