- API 模块按领域拆分为 `src/api/<domain>/index.ts`，每个文件仅暴露该领域的函数，统一通过 `@/utils/request` 的 `post/get/put/del` 发起请求。
- 所有 HTTP 响应使用泛型 `ApiResponse<T>` 包裹，请求侧通过 `post<T>(url, data)` 指定返回数据类型，避免在页面中重复断言。
- 路由跳转统一使用 `config/routes.ts` 导出的 `ROUTES` 常量字符串，禁止在页面中硬编码路径，同时导出 `PagePath` 类型用于类型安全。
- Token 相关操作集中在 `api/auth/index.ts` 的 `storeTokens`、`refreshAccessToken`、`logOut` 等函数内，通过 `uni.setStorageSync`/`removeStorageSync` 读写 `accessToken`/`refreshToken`/`openId`。
- 页面目录遵循 `pages/<feature>/<action>/index.vue(+scss/+d.ts)` 结构，列表/详情/编辑/新增等动作各自成子目录，分包根由 `pages.json` 的 `subPackages[].root` 声明。
- 平台差异通过 `#ifdef MP-WEIXIN` 条件编译块嵌入到业务逻辑中（如 `platform: 'WEIXIN'`），而非单独的文件分支。
