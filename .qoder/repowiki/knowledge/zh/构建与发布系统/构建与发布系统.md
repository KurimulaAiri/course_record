该仓库是一个多模块 Monorepo，包含 Spring Cloud 后端微服务、Vue3 管理前端、UniApp 小程序和 Node.js MCP 运维工具。各子模块使用各自独立的构建系统，没有统一的顶层构建脚本。

**后端（Spring Cloud）**：
- 基于 Maven 多模块项目，根目录 `class_times_record_back/pom.xml` 聚合 admin-service、auth-service、business-service、gateway、common 五个子模块
- 每个服务模块独立 `pom.xml` + `Dockerfile`，支持容器化打包
- 通过 `docker-compose.yml` 编排本地开发环境
- 单元测试位于各模块 `src/test/java` 下，使用 Spring Boot Test

**管理前端（Vue3）**：
- 基于 Vite + TypeScript + Element Plus，构建配置在 `vite.config.ts`
- 使用 pnpm 作为包管理器，测试使用 Vitest + Playwright E2E
- 提供 Jenkins Pipeline 配置文件 `pipeline/Jenkinsfile`

**小程序（UniApp）**：
- 基于 UniApp + Vue3，自定义构建脚本 `publish.ts` 负责多端发布流程
- 使用 pnpm 管理依赖，Vite 驱动开发体验

**MCP 运维工具**：
- Node.js/TypeScript 项目，提供 Dockerfile 和 docker-compose.yml
- 包含 Jenkinsfile 用于 CI 流水线
- 提供 `deploy.sh` 部署脚本和 `router_patch.py` 路由补丁工具

**CI/CD**：
- 各模块均提供 Jenkinsfile，但未见统一的根级 CI 配置
- 通过 `.run/` 下的 IDEA Run Configuration 支持本地一键启动多个微服务
- 数据库变更通过 SQL 文件和 `db-sync.sh` 脚本同步

**约定与约束**：
- 各模块独立维护版本和依赖，无统一版本号策略
- 构建产物通过 Docker 镜像形式分发
- 环境变量通过 Nacos 配置中心统一管理
